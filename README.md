# 📚 English Learning Hub

Welcome to **English Learning Hub** — a simple and interactive website designed to help learners improve their English grammar, vocabulary, tenses, and overall language skills.

## 🌐 About the Project

English Learning Hub is a front-end web project created to provide an easy-to-use platform for learning English.

The website includes:

- 📖 English Grammar
- ⏰ Complete English Tenses
- 🔄 Active & Passive Voice
- 📚 Vocabulary Learning
- 🎯 Practice Questions
- 🏆 English Mock Tests

## ✨ Features

### 🏠 Home
A simple and attractive landing section that introduces the English Learning Hub.

### ⏰ Tenses
Learn all **12 English Tenses** with:

- Tense names
- Formulas
- Examples
- Present Tense
- Past Tense
- Future Tense

### 📝 Grammar
A dedicated section for improving English grammar step by step.

### 🔄 Voice
Learn the basics of:

- Active Voice
- Passive Voice

### 📖 Vocabulary
Improve English vocabulary by learning new words and their usage.

### 🎯 Practice
Practice English questions and test your understanding.

### 🏆 Mock Test
Take an English mock test to check your overall knowledge.

## 🛠️ Technologies Used

This project is built using:

- **HTML5** — Website structure
- **CSS3** — Styling and responsive design
- **JavaScript** — Interactivity and functionality
